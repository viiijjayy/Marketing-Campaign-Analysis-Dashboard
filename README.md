# 📊 Marketing Campaign Analysis Dashboard | Excel

##  Project Overview

The **Marketing Campaign Analysis Dashboard** is an interactive Excel-based dashboard designed to analyze marketing campaign performance, audience engagement, conversion rates, and return on investment (ROI).

This project transforms raw marketing campaign data into actionable insights through interactive visualizations, KPI tracking, and dynamic filtering, enabling data-driven marketing decisions.

##  Business Objectives

- Evaluate marketing campaign performance across companies.
- Analyze conversion rates and ROI by company.
- Understand audience engagement and click behavior.
- Identify high-performing marketing channels.
- Analyze impressions across customer segments and locations.
- Support strategic marketing decisions through interactive data visualization.

##  Tools & Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Slicers
- Data Cleaning
- Data Analysis
- KPI Reporting
- Dashboard Design

## Key Performance Indicators (KPIs)

| KPI | Description |
|---|---|
| Total Conversion Rate | Measures campaign conversion performance |
| Total Impressions | Tracks campaign reach and visibility |
| Total Engagement | Measures audience interaction |
| Total Clicks | Evaluates audience click activity |

##  Dashboard Features

- Company-wise Conversion Rate Analysis
- Company-wise ROI Analysis
- Audience-wise Total Clicks
- Customer Segment-wise Impressions
- Location-wise Total Impressions
- Channel-wise Total Clicks
- Interactive filters for Location, Company, Target Audience, Age, Channel, and Customer Segment
- Dynamic KPI cards and charts

##  Key Insights

- TechCorp recorded the highest conversion rate among the analyzed companies.
- Miami and New York demonstrated strong campaign impression performance.
- Men represented the largest audience segment by total clicks.
- Marketing channels showed varying levels of click performance.
- Customer segments exhibited different impression patterns.

##  How to Use

1. Download the Excel workbook from this repository.
2. Open the workbook using Microsoft Excel.
3. Navigate to the Dashboard worksheet.
4. Use the slicers to filter campaign data by company, location, audience, age, channel, and customer segment.
5. Explore the charts and KPI metrics to identify campaign performance trends.

**Note:** Microsoft Excel desktop is recommended for the best interactive experience.
